# duckdb-odata Task Checklist — v0.3（导航属性与富类型）

> 依据：docs/design.md §5「v0.3：导航属性与富类型」。
> 状态图例：`[x]` 已完成并验证；`[ ]` 未完成/部分完成。

## 1. $expand 与导航属性（Milestone 7）

- [ ] 元数据模型引入关系描述：NavigationProperty / Association / Cardinality
- [ ] `CALL odata_entity(..., navigation := ...)` 或等价关系注册入口
- [ ] `GET /odata/orders?$expand=customer` 编译为 LEFT JOIN
- [ ] 单值导航（many-to-one）展开到 JSON 对象
- [ ] 集合导航（one-to-many）展开到 JSON 数组
- [ ] $metadata 输出 NavigationProperty 声明
- [ ] 展开深度限制 `odata_max_expand_depth`
- [ ] `$select` 作用于展开子属性（`customer/name`）

## 2. 富类型（richer types）

- [ ] LIST / ARRAY 列的类型建模与 JSON 序列化
- [ ] STRUCT 列 → 嵌套 JSON 对象
- [ ] MAP / UNION 类型策略（映射 or 显式不支持）
- [ ] JSON 类型（duckdb JSON 扩展列）处理
- [ ] HUGEINT 精度策略（Edm.Decimal 字符串 or 数字）
- [ ] INTERVAL / GEOMETRY 处理策略
- [ ] BLOB/二进制细粒度格式策略确认
- [ ] 复杂类型在 $filter / $select 中的行为定义

## 3. 分页与协议增强（从 v0.2 延续）

- [ ] `$skiptoken` 游标分页（稳定排序键方案）
- [ ] `$search` / `$apply` 等系统查询选项支持与否的明确结论

## 4. 序列化深度

- [ ] 嵌套对象/数组的流式 JSON 编码（不整包物化）
- [ ] `@odata.count` 在展开场景下语义确定

## 验收入口（目标）

```bash
GET /odata/orders?$expand=customer
GET /odata/customers?$expand=orders
# $metadata 含 NavigationProperty
```

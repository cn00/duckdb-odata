# duckdb-odata Task Checklist — v0.4（写操作与事务）

## 1. 写操作（Milestone 8）

- [ ] `POST /odata/{entity}` 新增实体（编译为 INSERT）
- [ ] `PATCH /odata/{entity}({key})` 部分更新
- [ ] `PUT /odata/{entity}({key})` 全量替换
- [ ] `DELETE /odata/{entity}({key})`
- [ ] 写操作与 read-only 模式的开关（odata_serve read_only 选项）
- [ ] 写操作的输入验证与类型转换（与查询共用类型映射）

## 2. 事务与并发控制

- [ ] 单请求写操作的事务包装
- [ ] `$batch`（原子多请求）
- [ ] ETag / If-Match（乐观并发）
- [ ] 修改响应：201/204 + Location 头
- [ ] 写操作鉴权（授权层前置校验）

## 验收入口（目标）

```bash
curl -X POST /odata/customers -d '{"name":"x"}'
curl -X PATCH /odata/customers(1)
curl -X DELETE /odata/customers(1)
```

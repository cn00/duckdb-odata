# duckdb-odata Task Checklist — v0.4（写操作与事务）

> 依据：docs/design.md §6「v0.4：写操作与事务」。
> 状态图例：`[x]` 已完成并验证；`[ ]` 未完成/部分完成。

## 1. 写操作（Milestone 8）

- [x] `POST /odata/{entity}` 新增实体（参数化 INSERT；201 + Location + 公开字段）
- [x] `PATCH /odata/{entity}({key})` 部分更新（参数化 UPDATE；禁止修改 key）
- [ ] `PUT /odata/{entity}({key})` 全量替换
- [x] `DELETE /odata/{entity}({key})`（参数化 DELETE；PATCH/DELETE 返回 204）
- [x] 写操作与 read-only 模式的开关（`odata_serve(..., read_only := false)`；默认只读）
- [x] 写操作的输入验证与类型转换（公开列校验、JSON 标量、catalog 类型 CAST；复杂类型和 BLOB 写入暂不支持）

## 2. 事务与并发控制

- [x] 单请求写操作的事务包装（约束失败/非唯一 key 命中多行时回滚）
- [ ] `$batch`（原子多请求）
- [ ] ETag / If-Match（乐观并发）
- [x] 修改响应：201/204 + Location 头
- [x] 写操作鉴权（Bearer + 实体/列白名单前置；尚无用户级 grant/RLS）

本批实现与限制见 [writes.md](../writes.md)。WSL + DuckDB v1.5.5 静态扩展构建、
原有 HTTP 回归及 `test/http/odata_write_test.py` 均已通过（2026-09-10）。

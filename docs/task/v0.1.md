# duckdb-odata Task Checklist — v0.1（OData 核心与基础写入占位发布）

> 依据：docs/design.md §3–§6；已实现的后续阶段能力归入本次 v0.1 占位发布。
> 状态图例：`[x]` 已完成并验证；`[ ]` 未完成/部分完成。
> 复核基准：`v0.1.0` tag 对应代码 + `test/http/odata_http_test.py` 全绿。
> 后续版本清单只保留尚未实现的工作，不作为 v0.1 占位发布的验收条件。

## 1. 工程骨架（Milestone 0）

- [x] DuckDB C++ extension 项目结构（CMakeLists / extension_config.cmake / Makefile）
- [x] Extension 入口：`INSTALL/LOAD odata`，extension 名 `odata`
- [x] DuckDB v1.5.5 本地源码构建 + loadable `.duckdb_extension` 产物
- [x] CI 基础：GitHub Actions `build-and-test.yml`（ubuntu/macos 构建 + ubuntu HTTP e2e，版本矩阵 v1.5.5）

## 2. SQL 生命周期 API（Milestone 1）

- [x] `CALL odata_serve('http://0.0.0.0:8080')` 启动服务
- [x] `CALL odata_serve()` 无参默认：localhost + 空闲端口 + 自动生成 token；返回一行 `listen_uri`/`listen_url`/`auth_token`（quack_serve 风格）
- [x] `CALL odata_serve(..., token := 'secret')` 可选 Bearer token（缺省自动生成；`token := ''` 显式关闭认证）
- [x] `CALL odata_serve(..., base_path := '/odata')` 自定义 base path
- [x] `CALL odata_serve(..., read_only := true)` 只读开关（默认只读）
- [x] `CALL odata_stop()` 停止服务
- [x] `SELECT * FROM odata_status()` 运行状态（running/address/base_path/token/entities；address 为实际监听 URL）

## 3. HTTP / OData 端点（Milestone 1-3）

- [x] `GET /health` → `{"status":"ok"}`
- [x] `GET /odata` 服务文档（列出已暴露 EntitySet）
- [x] `GET /odata/$metadata` 由 DuckDB catalog 实时生成 EDMX（不维护静态 XML）
- [x] `GET /odata/{entity}` 实体集合
- [x] `GET /odata/{entity}({key})` 与 `GET /odata/{entity}/{key}` 单实体查询
- [x] 多 schema 支持：`GET /odata/s1_customers`（`odata_expose('s1.customers')`）
- [x] 默认只读约束：未显式启用写入时，仅允许 GET，其余方法返回 405
- [x] 统一 OData 错误 JSON `{"error":{"code","message"}}`（4xx/5xx）
- [x] HTTP 层抽象：自维护 socket 后端、可替换（方案 B）
- [x] 未知 `$` 系统选项返回 400（不静默忽略）

## 4. EntitySet 定义与元数据（Milestone 2-3）

- [x] DuckDB table = OData EntitySet
- [x] 默认策略：不暴露任何表（白名单）
- [x] `CALL odata_expose('customers')` 单表暴露（支持 `'s.customers'`/`'db.s.customers'`；返回 `(entity, table)` 映射行）
- [x] `CALL odata_expose_schema('main')` / `('s1')` / `('db1.main')` 按 schema 批量暴露（可指定 attach 库 catalog；每表返回一行 `(entity, table)`）
- [x] EntitySet 相对命名：当前 catalog+schema 用裸表名，非当前 schema 前缀 `s_`，非当前 catalog 前缀 `db_s_`（避免跨库冲突）
- [x] `CALL odata_entity('customers', key := 'id')` 显式 key 配置
- [x] key 自动发现兜底：单列 PRIMARY KEY → 首列
- [x] 类型映射：DuckDB 标量类型 → EDM（BOOLEAN…BLOB）
- [x] 元数据中 catalog/schema 精确定位（避免跨库串扰）

## 5. 查询选项（Milestone 4）

- [x] `$select` 列投影 + 列存在性校验（杜绝 `$select` 直达 SQL）
- [x] `$filter` v0.1 算子：`eq ne gt ge lt le and or not ( )`
- [x] `$filter` 扩展字符串函数：contains/startswith/endswith/tolower/toupper/length/substring/concat/indexof/trim
- [x] `$filter` 时间/数学函数：year/month/day/hour/minute/second/now/round/floor/ceiling/abs
- [x] `$orderby` 多列 + asc/desc
- [x] `$top` / `$skip`（含 OFFSET/LIMIT 顺序）
- [x] 服务端 `$top` 上限 `odata_max_top`
- [x] `$count=true` → `@odata.count`（MVP 独立 COUNT 查询）
- [x] 集合响应输出 `@odata.nextLink`（基于受校验 `$skip` 游标）
- [x] 默认页大小与 `odata_page_size` 配置

## 6. OData → SQL 编译管线

- [x] Lexer → Parser → AST（parser/lexer.*、parser/ast.hpp）
- [x] ODataQuery 结构化查询模型
- [x] 语义验证：属性/函数白名单（未知属性、未知函数 → 400）
- [x] AST → DuckDB SQL string（表达式编译器 + SQL 编译器）
- [x] 标识符转义 `QuoteIdentifier`（防注入硬约束）
- [x] 字面量安全渲染：字符串单引号转义、按列类型 `CAST`
- [x] catalog/schema 全限定 SQL 引用（`"catalog"."schema"."table"`）

## 7. 执行与序列化

- [x] `QueryExecutor` 抽象 + `LocalDuckDBExecutor`
- [x] DuckDB Value → JSON 标量输出（数字/布尔/字符串/Null；Date/Time/Timestamp/UUID 字符串；BLOB base64）

## 8. 安全（Milestone 5）

- [x] Bearer Token 认证（`Authorization: Bearer <token>`，常量时间比较）
- [x] 实体白名单授权（默认不暴露）
- [x] 列级白名单：`odata_expose('customers', columns := ['id', 'name'])`
- [x] 默认 GET-only；`read_only := false` 才允许写入
- [x] 防 SQL 注入链路：AST → 类型化字面量 → SQL
- [x] `odata_max_top`、`odata_max_filter_depth`、`odata_max_response_bytes`、`odata_query_timeout_ms` 与 `odata_max_concurrent_queries` 强制资源限制
- [x] 超出 `odata_max_response_bytes` 时返回 413
- [x] 查询超时中断

## 9. 基础写操作

- [x] `POST /odata/{entity}` 新增实体（参数化 INSERT；201 + Location + 公开字段）
- [x] `PATCH /odata/{entity}({key})` 部分更新（参数化 UPDATE；禁止修改 key）
- [x] `DELETE /odata/{entity}({key})`（参数化 DELETE；PATCH/DELETE 返回 204）
- [x] `PUT /odata/{entity}({key})` 全量替换（请求体须包含所有公开的非 key 字段）
- [x] `odata_serve(..., read_only := false)` 显式开启写操作；默认只读
- [x] 写操作输入验证与类型转换（公开列校验、JSON 标量、catalog 类型 CAST；复杂类型和 BLOB 写入暂不支持）
- [x] 单请求写操作事务包装（约束失败或非唯一 key 命中多行时回滚）
- [x] 写操作返回 201/204 与 Location 头
- [x] 写操作继承 bearer 认证与实体/列白名单
